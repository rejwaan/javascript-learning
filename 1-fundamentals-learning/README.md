# JavaScript Fundamentals Learning

This folder contains my JavaScript fundamental learning practice from multiple learning sources.

The main goal of this folder is to build a strong understanding of **JavaScript basics and core fundamentals** by learning from different tutorials, videos, and practice exercises.

- Follow structured tutorials from different sources
- Practice core JavaScript concepts through coding
- Experiment with small examples to understand behavior
- Build consistency in daily learning

- Objects

- Problem Solving Practice
