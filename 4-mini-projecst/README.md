# JavaScript Mini Projects

This folder contains small JavaScript mini projects built for practice and hands-on learning.

The main goal of this folder is to apply JavaScript fundamentals by building small real-world-like projects.

## 🚀 What I Do Here

- Build small interactive projects using JavaScript
- Apply logic, DOM manipulation, and events
- Combine HTML, CSS, and JavaScript in simple apps
- Experiment with different ideas and features

- Simple calculator
- Counter app
- Digital clock
- Basic form validation
- Random generator apps

## 🧠 Learning Focus

- DOM manipulation
- Event handling
- Functions and logic building
- Problem-solving in real scenarios
